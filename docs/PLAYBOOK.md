# Из чего собирать экраны

Готовые блоки лежат в `template/src/components` и копируются в каждый новый
проект. Перед тем как писать свой компонент — посмотрите, нет ли подходящего
здесь. Свой пишется, только если ни один не ложится; тогда кладите его в
`template/src/components`, чтобы следующий мини-апп получил его даром.

## Справочник блоков

| Блок | Для чего | Обязательные пропсы |
|---|---|---|
| `SectionTitle` | Заголовок раздела, с подзаголовком и выравниванием | `title` |
| `PageHeader` | Шапка внутренней страницы с возвратом на главную | `title` |
| `ServiceCard` | Плитка услуги, ведёт на свою страницу | `href`, `icon`, `title`, `subtitle`, `gradient` |
| `FeatureCard` | Что входит / чем хороши — без перехода | `icon`, `title`, `description` |
| `CaseCard` | Кейс с цифрами | `tag`, `tagColor`, `title`, `metrics` |
| `StatBlock` | Одна крупная цифра | `value`, `label`, `color` |
| `ProcessStep` | Шаг процесса в вертикальной цепочке | `number`, `title`, `description`, `color` |
| `PricingCard` | Тариф со списком включённого | `name`, `price`, `description`, `features`, `color` |
| `FAQ` | Вопросы-ответы, раскрываются по клику | `items` |
| `LeadForm` | Форма заявки, шлёт на `/api/lead` | `fields`, `buttonText`, `service` |
| `BottomCTA` | Нижний призыв с формой | `title`, `subtitle`, `color`, `service` |
| `CTAButton` | Кнопка: ссылка или обработчик | `children` |

Пропсы сверяйте по самому файлу — перечислены только обязательные. Частая
ошибка: передать `subtitle` в `PageHeader`, у которого его нет, и получить
красную сборку.

## Типовая раскладка одноэкранного мини-аппа

1. `SectionTitle` — оффер в одну строку и подзаголовок с выгодой
2. Три-четыре `FeatureCard` — что человек получит
3. `ProcessStep` — как это работает, 3-4 шага
4. Один-два `CaseCard` — доказательство
5. `PricingCard` — если цены открытые
6. `FAQ` — снимает типовые возражения
7. `BottomCTA` — целевое действие

## Многоэкранный

Главная — плитки `ServiceCard`, каждая ведёт на `/<услуга>`. Внутренняя
страница начинается с `PageHeader` (в нём возврат), дальше как одноэкранный
без повторного оффера.

## Правила вёрстки

- Ширина контента — `max-w-screen-sm mx-auto`. Мини-апп открывают с телефона,
  растянутый на весь десктоп текст читается плохо и выглядит как недоделанный
  сайт.
- Отступы по краям `px-4` — под системные панели Telegram.
- Фиксированных ширин в пикселях не ставьте: на узких экранах блоки разъедутся,
  а сборка этого не поймает.
- Цвета берите из переменных `globals.css` (`--color-text`, `--color-border`
  и прочие). Захардкоженный цвет выпадет из темы.

## Проверка перед сдачей

- `scripts/check.sh <имя>` — зелёный
- `scripts/preview.sh <имя>` — открывается
- каждая страница отдаёт свой текст: `curl -s localhost:3400/<путь> | grep <фраза>`
- ни одной кнопки с `href="#"`
- форма заявки реально доходит: с заполненным `.env.local` ответ `{"ok":true}`
